\# Checkers 3D — Game QA



\## About the Project



Checkers 3D is a local multiplayer checkers game developed using Unreal Engine 5.



The game is designed for two players using the same PC.



This project was used as a practical case for manual QA testing and analysis of game logic.



\---



\## Project Information



| Parameter | Value |

|---|---|

| Engine | Unreal Engine 5 |

| Platform | Windows |

| Game Mode | Local Multiplayer |

| Players | 2 |

| Testing | Manual QA |



\---



\## Tested Functionality



\- Piece selection

\- Piece movement

\- Capturing opponent pieces

\- Multiple captures

\- Turn switching

\- Game board interaction

\## Known Limitations



The current version of the project does not include:



\- King promotion

\- Game restart functionality

\- Dedicated game-end screen

\- Automatic winner determination

\- In-game exit menu

\- Online multiplayer



These limitations represent functionality that was not implemented in the current version of the project.
